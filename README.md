Course repository for **CSE 340 - Web Backend Development**. This repository serves as a centralized portfolio of all coursework, reading reflections, and practical coding projects completed throughout the semester. 

## 🎯 Course Overview

This repository demonstrates practical implementation of server-side web development principles. Key concepts covered in this course include:
*   Building robust API endpoints and routing
*   Database design, management, and integration
*   Server-side rendering and templating
*   Authentication, authorization, and security protocols
*   Model-View-Controller (MVC) architecture
*   Error handling and application testing

## 🛠️ Technologies & Tools

*   **Runtime Environment:** Node.js
*   **Framework:** Express.js
*   **Database:** PostgreSQL / MySQL (Adjust as needed)
*   **Templating Engine:** EJS / Pug (Adjust as needed)
*   **Version Control:** Git & GitHub
